R & Z Store

Modern E-Commerce Website | ASP.NET Core MVC

R & Z Store is a modern online shopping platform focused on mobile phone accessories. The project is built using ASP.NET Core MVC with a layered architecture, providing a structured and maintainable foundation for an e-commerce business.

Project Overview

The main goal of this project is to develop a complete online store where customers can browse products, manage their shopping carts, and place orders. It also includes an administration panel for managing store operations.
